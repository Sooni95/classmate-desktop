코코메이트 개인정보처리방침

최종 수정일: 2026.06.24

네패스 Kokoafab(이하 "회사")이 제공하는 데스크탑 수업 보조 도구 코코메이트(이하 "앱")의 개인정보 처리 방침입니다. 코코메이트는 별도 회원가입·로그인이 없으며, 광고를 게재하지 않고, 사용 행태를 추적하는 분석 도구를 탑재하지 않습니다.

1. 다운로드 시 수집하는 정보

웹사이트에서 앱을 다운로드하실 때, 아래 정보를 입력받아 회사 서버(Cloudflare)에 저장합니다.

수집 항목소속, 성명, 직급, 전화번호, 이메일
수집 목적다운로드 이용자 확인, 문의 응대, 서비스 개선을 위한 이용 현황 파악
보유 기간수집일로부터 3년 또는 동의 철회 시까지

위 정보 제공은 다운로드를 위해 필수이며, 동의하지 않으실 경우 다운로드가 제한됩니다. 마케팅 정보(신규 기능·업데이트 소식 등) 수신 동의는 선택 사항으로, 동의하지 않아도 다운로드에는 영향이 없습니다. 동의 철회 및 정보 삭제는 7항 문의처로 요청하실 수 있습니다.

2. 기기 안에만 저장되는 정보

다음 정보는 외부로 전송되지 않고 사용자 PC(앱 데이터 폴더)에만 저장됩니다.

  • 저장한 학생 명단, 모둠·점수 등 수업 데이터
  • 앱 설정(테마, 독 구성, 소음 기준값 등)
  • 사용자가 입력한 AI API 키(직접 키 사용 시)

이 정보는 앱을 삭제하면 함께 사라집니다.

3. 기능 사용 시 외부로 전송되는 정보

특정 기능을 사용할 때에 한해 아래와 같이 데이터가 처리됩니다. 사용하지 않으면 전송되지 않습니다.

기능전송되는 내용처리 주체목적
AI 교수 보조사용자가 입력한 질문 텍스트Anthropic(Claude API)답변 생성
다문화 번역번역할 텍스트Anthropic(Claude API)번역
실시간 자막(Pro)마이크 음성(짧은 구간)회사 서버(Cloudflare) 경유 → OpenAI(Whisper)음성→텍스트 변환
단축URL 생성원본 URL과 단축 이름회사 서버(Cloudflare Workers/KV)단축주소 발급·연결
의견 보내기작성한 의견, (선택)회신 연락처회사 서버 → 담당자 메일문의·개선

전송된 데이터는 위 목적에 한해 사용되며, 회사는 이를 광고·프로파일링·제3자 판매에 이용하지 않습니다. 외부 처리 주체(Anthropic, OpenAI, Cloudflare, GitHub)는 각 사의 정책에 따라 데이터를 처리합니다.

4. 마이크·화면 권한

마이크: 소음 측정과 실시간 자막에만 사용됩니다. 소음 측정의 음량 계산은 기기 안에서만 이루어지며 녹음·전송되지 않습니다.

화면 캡처: 핀·칠판 기능에서 사용자가 선택한 영역을 캡처하며, 결과는 사용자 기기 안(클립보드·저장 파일)에 머뭅니다. 회사 서버로 전송되지 않습니다.

5. 아동 및 학생 정보

코코메이트는 교사용 도구로, 학생 개인정보 입력을 요구하지 않습니다. 명단 등 교사가 입력하는 정보는 기기 안에만 저장됩니다(2항). 교사는 실명 대신 번호·별칭 사용을 선택할 수 있습니다. 회사는 학생 개인정보를 수집·보관하지 않습니다.

6. 보관 및 파기

  • 다운로드 시 수집한 정보: 1항에 명시된 보유 기간 경과 또는 동의 철회 시 파기됩니다.
  • 기기 내 정보: 사용자가 삭제하거나 앱을 제거할 때까지 보관됩니다.
  • 단축URL: 사용자가 설정한 만료 기한이 지나면 서버에서 자동 삭제됩니다.
  • 의견 보내기: 문의 처리 목적 달성 후 합리적 기간 내 파기합니다.
