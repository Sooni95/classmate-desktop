코코메이트 설치 안내

처음 실행할 때 뜨는
보안 경고, 이렇게 넘기세요

아직 정식 서명 인증서가 없는 베타 버전이라, Windows·macOS 모두 "출처를 확인할 수 없다"는 경고가 한 번 뜹니다. 악성코드가 아니라 인증서 비용 문제라, 아래 순서대로 한 번만 눌러주시면 됩니다.

🪟

Windows

"Windows에서 PC를 보호했습니다" 화면이 뜨는 경우

1
다운로드한 KocoMate-portable.exe를 더블클릭
아래와 같은 파란 화면이 뜨면 정상입니다 — 삭제하지 마세요.
🛡️
Windows에서 PC를 보호했습니다 Microsoft Defender SmartScreen에서 인식할 수 없는 앱의 시작을 차단했습니다. 이 앱을 실행하면 PC가 위험할 수 있습니다.
앱:KocoMate-portable.exe
게시자:알 수 없음
추가 정보 실행 안 함
2
"추가 정보"를 클릭
숨어있던 실행 버튼이 나타납니다.

macOS

"확인할 수 없는 개발자" 또는 "손상되었다"는 창이 뜨는 경우

1
dmg 파일을 열어 코코메이트를 Applications 폴더로 드래그
일반적인 Mac 앱 설치와 동일합니다.
2
Applications에서 아이콘을 일반 더블클릭 대신 우클릭
트랙패드는 두 손가락 클릭, 키보드는 control 키를 누른 채 클릭하세요.
열기
정보 가져오기
복제 ⌘D
휴지통으로 이동
3
뜨는 창에서 "열기" 클릭
우클릭으로 열면 일반 더블클릭과 달리 "열기" 버튼이 바로 보입니다.
🦋
확인되지 않은 개발자가 배포한 앱입니다.
정말 열겠습니까?

Apple은 이 앱에서 악성 소프트웨어가 있는지 확인할 수 없습니다. 신뢰할 수 있는 앱인지 확인 후 여세요.

Finder로 이동 취소 열기
이 확인은 처음 한 번만 필요합니다. 다음부터는 바로 열려요.
4
그래도 안 열리면 시스템 설정에서 직접 허용
간혹 위 방법으로도 막히면, 아래 경로에서 "확인 없이 열기" 버튼을 눌러주세요.
📍 시스템 설정 → 개인정보 보호 및 보안 → 맨 아래 "코코메이트"가 차단됨 안내 옆 확인 없이 열기
